# Diagramas Mermaid

A partir da etapa 2, os capítulos em `docs/` conterão blocos Mermaid renderizáveis diretamente no GitHub.

**Fonte de verdade:** o Mermaid embutido em cada capítulo Markdown. Eventuais arquivos `.mmd` deste diretório serão **extraídos/gerados**, e não uma segunda versão mantida manualmente. Esse processo será definido e automatizado na etapa 7.

| Etapa | Diagrama planejado |
| --- | --- |
| 2 | Contexto do sistema |
| 3 | Contêineres |
| 4 | Componentes internos da API |
| 5 | Classes do caso de uso de saída |
| 6 | Sequência ou dinâmica da movimentação |
